==========================================
Overview
==========================================

The focus of Geo-projected Ground Motion ARD (GGM) is on deformation
applications. The idea is combining displacement information from two (or more when possible)
acquisition geometries in order to identify three-dimensional displacement measurements,
no longer in the SAR reference system (azimuth, slant range) but in a geographic reference
system. This three-dimensional geo-projected displacement information would evidently be extremely
useful in many application contexts (such as ice tracking, analysis of deformations due
to various phenomena such as earthquakes, subsidence etc.).
