\subsection{Purpose of the Document}
This document reports the Algorithm Theoretical Baseline Document (ATBD) for \acs{ard} product generation starting from the state-of-the-art analysis D1~\cite{D1} associated to the following products: 

	\begin{itemize}
		\item Co-registered Single Look Complex (CSLC/GSLC)
		\item Normalized Radar Backscatter (NRB/ENRB)
		\item Polarimetry (COV/GCOV)
		\item Ocean Radar Backscatter (ORB/EORB)
		\item Co-registered multilooked phase (CMLC/GMLC)
		\item Interferometric products (INT/COHE/UNW/GINT/GCOHE/GUNW)
		\item Precise Range / Azimuth Offsets (PRO/PAO/GPRO/GPAO)
		\item Stripmap Equivalent (STRIPEQ)
		\item Geocoded Ground Motion (GGM)
	\end{itemize}
