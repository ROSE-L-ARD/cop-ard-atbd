\section{Comparative Analysis and Ranking}

\autoref{tab:cmp_analysis_ranking} contains a comparative analysis and ranking of all products. To make it more readable, the following acronyms have been used:
\begin{itemize}
    \item \textbf{REL}: Relevance to ROSE-L Objectives and Use case coverage; 
    \item \textbf{ARR}: Algorithm Robustness and Reliability;
    \item \textbf{PAC}: Precision and Accuracy; 
    \item \textbf{INTO}: Interoperability; 
    \item \textbf{TCE}: Timeliness and Computational Efficiency; 
    \item \textbf{CS}: Compliance to Standards; 
    \item \textbf{SAVR}: Software Availability and Reusability; 
    \item \textbf{DRC}: Data Requirements and Constraints;
    \item \textbf{IR}: Implementation Risk; 
    \item \textbf{KL}: Known Limitations.
\end{itemize}
